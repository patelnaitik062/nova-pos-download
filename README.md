# NOVA POS for Android

Download the ready-to-install Android app from the [latest release](https://github.com/patelnaitik062/nova-pos-download/releases/latest).

1. Download `nova-pos-release.apk` to your Android phone.
2. Open the downloaded APK and follow Android's install prompt. If Android asks, allow installs for the browser or file manager you used.
3. Launch **NOVA POS**.

This repository is a public download mirror and contains the installer only. Source code and release-signing credentials are kept private. The app package is `com.nova.pos`.
